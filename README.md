# Home Stock Manager

Sistema de stock hogareño. Permite registrar productos escaneando tickets de supermercado y controlar el consumo.

## Stack
- **Backend**: Java 21 + Spring Boot 3 + PostgreSQL
- **Frontend**: React 18 + Vite + TailwindCSS

## Correr localmente

### Backend
```
cd backend
mvn spring-boot:run
```

### Frontend
```
cd frontend
npm install
npm run dev
```

Abrir http://localhost:5173
